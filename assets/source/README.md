# Source art

The original files for New Year Crackers live in Darshan's folder
`Kiyaan Gaming/01_GAMES/01_New_Year_Crackers/assets/images` (mockups at 4108 x 2220, symbols at 3000-5000 px).
They are not copied here because of their size (about 125 MB); `tools/asset-pipeline/` rebuilds the game files from them
(see `assets/README.md`).

The X-Mas Dolls source art that used to be in this folder is in https://github.com/fxdarshan/Demo-SLot-Game.
